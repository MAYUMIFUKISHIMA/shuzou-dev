# 確定要件

- 焼酎製造会社の製造部門、10人、1拠点。紙の作業・仕込み〜蒸留記録を電子化。
- Supabaseに保存。既存の生産管理システムとの直接API連携は対象外。
- メールアドレスを持つ作業員が会社貸与の共用Androidで利用。
- 圏外でも一時保存。再接続後、画面を開いて送信でき、未送信件数と結果を確認できること。閉じたブラウザでの自動同期は保証しない。
- ログアウトや作業員切り替え時には未送信分を破棄。件数を示して確認し、前の人のデータを次の人に残さない。
- 作業員は自分の記録のみ閲覧・修正。管理者は全件閲覧・修正・削除。承認工程なし。
- 削除後24時間まで管理者が復元可能。
- 仕込み番号あり。途中に混合・分割あり。元の仕込みと移動量の対応を追跡する。
- 管理者が毎月CSVをダウンロードし、社内保存完了を明示的に確認する。
- クラウド削除対象は「一連の製造完了から1年経過」かつ「社内保存確認済み」。以前の3か月案は廃止。
- 全製造原価を仕込み単位・月単位で把握。原料数量・単価は既存システムからCSVで手動取り込み。
- 労務費・光熱費・減価償却費などの保存先と配分ルールは未確認。未登録費用がある集計は暫定原価として示す。
- 仕込み時点の情報から蒸留後の純アルコール数量を予測したい。過去実績は社内で継続保存し、分析に利用。
- クラウド・AI利用の社内制約なし。無料枠優先。容量・利用量・バックアップ要件により費用の再評価が必要。

## 後日必要な資料

紙帳票、原料CSVサンプル（匿名化可）、混合・分割の記入例、費用データと配分基準、純アルコール数量の単位と計算基準。保存確認後の記録修正やCSV再出力も設計に含める。
